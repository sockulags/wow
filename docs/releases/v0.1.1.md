# wow 0.1.1

The first update to 0.1.0, delivered through auto-update: an installed 0.1.0 finds it, downloads it
in the background and offers "Restart to update". It fixes the three known gaps from 0.1.0 and
reworks the interface after a full design review.

## Fixes

- Codex works in the installed app: the bundled server registers the Codex adapter, with the new
  `providers.requestTimeoutMs` setting (#19).
- Projects: Settings → Projects creates, renames and removes projects, picks the folder with the
  system folder dialog, and imports the folders Claude and Codex have worked in (#21).
- Chat: threads can be marked done and reopened; the "Done" group fills (#20).
- The palette no longer loses Ctrl+K pressed right after Escape, and shortcuts work while it is
  open (#25). Calendar zoom keys no longer also zoom the page (#22).

## Interface

- Every list and dropdown uses the app's own themed controls, also in the dark theme (#23).
- Calendar: zoom (Ctrl+wheel, Ctrl+= / Ctrl+- / Ctrl+0, toolbar), overlapping meetings side by
  side, a now-line, keyboard navigation between items, meeting details with Join and Open in
  Outlook, end-before-start validation, a foldable mail rail and an option to hide weekends (#22,
  #26).
- Time zone, work hours and first day of week come from Outlook unless overridden (#26).
- Shared design system: one pattern for empty, loading and disconnected states, toasts with Undo
  for deletions, tooltips with keys, consistent fields and dialogs, layout down to 800 px, no
  Electron default menu in the installed app (#24).
- First run walks through providers and projects and remembers "Not now"; provider tests run on
  their own; setting keys are hidden unless Advanced → "Show setting keys" is on (#24).
- Chat, workflows and backlog: starters in a new thread, last used provider and model preselected,
  Continue and Stop in a step's thread, approval keys, code highlighting, Jira bodies in Jira markup
  (#25).
- Context panel (Ctrl+J, F6 to focus): the selected card, meeting, run, workflow, backlog item or
  thread with its details, and a card's live step thread next to the calendar (#28).
- Trackers per project: GitHub owner and repository are read from the project's git remote, Jira
  suggestions come from commit and branch names, and the publish preview names the target (#27).

## Known gaps

None are known; see "Known gaps" in `docs/user-guide.md`.
