# wow 0.1.2

Codex versions: wow no longer requires the exact codex release it was built against.

## Changes

- **Compatible codex versions work.** When the installed codex differs from the tested one
  (0.166.0), "Test" reads that codex's own protocol schema and checks the methods and fields wow
  uses. A compatible version is Ready with a notice; an incompatible one lists exactly what is
  missing. Checked against real codex 0.164.0 and 0.130.0 (compatible) and 0.100.0 (incompatible)
  (#31).
- **Update Codex from Settings.** For an npm-installed codex that is incompatible or older than the
  tested version, Settings → Providers offers "Update Codex to 0.166.0". After a confirmation that
  names the command, wow runs `npm install -g @openai/codex@0.166.0`, shows the output and tests
  again. Other installs get the exact instruction (#31).
- Fixed: a successful codex Test could be recorded as an error, and a codex notification without
  parameters stopped the adapter (#31).
- **New codex releases are picked up automatically.** A daily workflow regenerates the codex
  protocol for each new stable codex release and opens a pull request, so support ships as a wow
  update (#30).

## Known gaps

- The "Update Codex" button has only been tested against a fake npm; the first real run is on the
  owner's machine.
