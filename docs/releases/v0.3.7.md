# wow 0.3.7

wow no longer watches a project's own folder. That watch is the likely reason a project folder
could not be removed or moved on Windows while wow ran, since 0.3.4.

Built and reviewed by agents, run against mock agents and mock hosts only. Read "Known gaps".

## Changes

- **Only folders that exist are watched.** wow watches a project's `intents` folder for plans and
  its `.claude/skills` and `.agents/skills` folders for skills. When one of them did not exist,
  the watch fell on the folder above, usually the project's own folder, and on Windows a watched
  folder cannot be renamed or removed. A folder that does not exist is no longer watched at all.
- **A folder made later is still found.** Plans are read again when the Plans view opens or is
  refreshed, when a project or a setting changes, and after a turn or a run step ends. A first
  skill written by hand into a project is listed after the next turn ends or with "Refresh
  skills".

- **The card form opens on the times the calendar shows.** A card moved or resized with the keys
  a moment before opened its form on the stored times, and saving the form put the old times
  back.
- **A thread's commands reach the agent in the order you gave them.** A turn's start first reads
  the folder for the thread's changes, which can take seconds on Windows; a message handed to the
  running turn, or a stop, could reach the agent before the start it belonged to.

## Known gaps

- Nothing in this release has been run against a real Claude Code or Codex, a real host, or on
  Windows outside CI.
- That this was what held the folder is read from the watch library's code and from a Windows
  test run that showed the folder held with no git running. The Windows test runs of this release
  showed the folder held once per run where it was three times before, so most of it is gone
  and not all.
- A project that has an `intents` folder or a skills folder is still watched there. On Windows
  that may still keep the project's folder from being renamed or removed while wow runs. Close
  wow first if Windows refuses.
- The other gaps of 0.3.5 stand; see `docs/releases/v0.3.5.md`.
